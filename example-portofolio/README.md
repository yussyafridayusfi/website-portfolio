# Portfolio

A brutalist one-page portfolio built with React, TypeScript, Vite, TailwindCSS, and Framer Motion.

## Features

- **Brutalist Design**: Bold typography, high contrast, thick borders
- **2x2 Grid Layout**: About, Projects, Blog, Contact sections
- **Smooth Animations**: Staggered reveals and hover effects
- **Responsive**: Adapts to mobile devices

## Tech Stack

- React 19
- TypeScript 5.9
- Vite 8
- TailwindCSS 4
- Framer Motion

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linter
npm run lint
```
